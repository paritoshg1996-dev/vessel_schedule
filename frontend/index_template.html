Data sources & how this works

Vessels currently on berth and expected-arrival data (voyage, service, line, ETA, gate cut-off) are both pulled directly from each of the 5 container terminals' own PDF reports. JNPA's port-wide daily berthing report is used separately to discover each terminal's current report link and to confirm today's data has actually been published.

    Rows marked SAMPLE are placeholder data for terminals whose automated feed isn't connected yet — they illustrate the expected-vessel view and are never real operational data.
